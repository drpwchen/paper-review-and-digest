# Security

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** (private vulnerability reporting). Please do not open a public issue for security problems.

These skills read papers and may call external services (CrossRef, optional publisher full-text APIs, an optional review-card site) using keys you put in your own `config.yaml`. In scope: anything that could leak those keys, or let a crafted paper or reference list make the skills run commands or write files outside what the README describes.

這些 skill 會讀論文，並用你自己 `config.yaml` 裡的 key 呼叫外部服務（CrossRef、選用的出版社全文 API）。發現可能洩漏 key，或惡意論文能讓 skill 執行非預期指令的問題，請從本 repo 的 **Security** 分頁選 **Report a vulnerability** 私下通報，不要開公開 issue。
